# 🛒 Omni Market

A modern **Full-Stack eCommerce Web Application** built with **React.js, Node.js, Express.js, and MySQL**. Omni Market provides a seamless online shopping experience with secure authentication, dynamic product management, and a responsive user interface.

---

## 🚀 Features

- 🔐 User Authentication & Authorization
- 🛍️ Product Browsing
- 🔎 Search & Filter Products
- 🛒 Shopping Cart
- ❤️ Wishlist
- 📦 Order Management
- 👤 User Profile
- 📱 Fully Responsive Design
- ⚡ Fast & Interactive UI
- 🗄️ MySQL Database Integration
- 🔄 RESTful APIs
- 🌐 Dynamic Data Fetching

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/omni-market.git
```

### Install Dependencies

Frontend

```bash
cd frontend
npm install
npm start
```

Backend

```bash
cd backend
npm install
npm run dev
```
